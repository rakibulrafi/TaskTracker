## 📌 Project Overview

TaskTracker is a simple command-line task management application developed using **C# .

The purpose of this project is to practice:

- C# programming fundamentals
- Console application development
- Git version control workflow
- Branching and merging

This project was developed as a hands-on learning project .

---

# 🚀 Features

## ✅ Add Tasks

Users can create new tasks and store them temporarily during program execution.

## ✅ View Tasks

    Users can view all the created task by him during program execution
    
## ✅ Edit Tasks

 Users can edit his added tasks if made any mistake when added any task on the time of program execution

## ✅ Delete Tasks

Users can delete his added task if he/she wishes to do
